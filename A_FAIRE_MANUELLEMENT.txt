┌──────────────────────────────────────────────────────────────┐
│ 1️⃣  TABLE WEIGHT_ENTRIES (SUIVI DE POIDS)                   │
└──────────────────────────────────────────────────────────────┘

SYMPTÔME:
- Dashboard affiche: "Erreur: La table weight_entries n'existe pas"
- Impossible de sauvegarder le poids

SOLUTION:
1. cPanel → phpMyAdmin
2. Sélectionnez votre base de données FitGang
3. Cliquez sur "SQL"
4. Copiez-collez ce code:

CREATE TABLE IF NOT EXISTS weight_entries (
    id INTEGER PRIMARY KEY AUTO_INCREMENT,
    user_id INTEGER NOT NULL,
    weight DECIMAL(5,2) NOT NULL,
    notes TEXT,
    recorded_at DATETIME NOT NULL DEFAULT CURRENT_TIMESTAMP,
    created_at DATETIME DEFAULT CURRENT_TIMESTAMP,
    updated_at DATETIME DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,

    FOREIGN KEY (user_id) REFERENCES users (id) ON DELETE CASCADE,
    INDEX idx_weight_entries_user_id (user_id),
    INDEX idx_weight_entries_recorded_at (recorded_at)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_unicode_ci;

5. Cliquez "Exécuter"
6. Testez: https://fitgang.fr/dashboard → Ajoutez un poids

│ 2️⃣  VÉRIFIER LES IMAGES DU BLOG                             │
└──────────────────────────────────────────────────────────────┘

SYMPTÔME:
- Les images ne s'affichent pas sur https://fitgang.fr/blog

DIAGNOSTIC:
1. Allez dans phpMyAdmin → Table blog_posts
2. Regardez la colonne "featured_image"
3. Les valeurs devraient être du type:
   - "blog/image-article.jpg" (LOCAL)
   - OU "https://..." (URL complète)

SI LES IMAGES SONT VIDES:
- Réditez vos articles dans /admin/blog
- Uploadez de nouveau les images
- Sauvegardez

SI LES CHEMINS SONT INCORRECTS:
- Vérifiez que les fichiers existent dans:
