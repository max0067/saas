🏋️ GUIDE: CRÉER DES WORKOUTS POUR TES PROGRAMMES
=====================================================

Le diagnostic a montré que tu as:
✅ 2 commandes COMPLETED
✅ 2 produits achetés (Programme sèche + Ebook)
❌ 0 workouts dans la base de données

C'est pour ça que tu vois "Aucun entraînement disponible"!


=====================================================
📋 SOLUTION: INTERFACE ADMIN WORKOUTS
=====================================================

J'ai créé une NOUVELLE interface admin super simple pour
créer des workouts en 1 clic!


ÉTAPE 1: Déployer les changements
----------------------------------
Sur le serveur SSH:

cd ~/public_html/saas
git pull origin claude/saccra-fitgang-complete-overhaul-0186TzukF7j2eifnrXaNd51n
find . -name "*.pyc" -delete
find . -name "__pycache__" -type d -exec rm -rf {} + 2>/dev/null

Puis dans cPanel → Setup Python App:
1. STOP APPLICATION
2. Attendre 1 minute
3. START APPLICATION


ÉTAPE 2: Créer des workouts
---------------------------
1. Va sur: https://fitgang.fr/admin/workouts

2. Tu verras tous tes produits (Programme sèche + Ebook)

3. Pour CHAQUE produit, tu as 2 options:

   OPTION A - CRÉATION RAPIDE (Recommandé!)
   ----------------------------------------
   - Clique sur "Créer automatiquement"
   - Choisis la semaine (ex: 1)
   - Choisis le nombre de jours (3, 4, 5, 6 ou 7)
   - Clique sur "Créer automatiquement"

   💥 BOOM! 5 workouts créés en 1 seconde avec:
   - Jour 1: Séance Push (Pectoraux, Épaules, Triceps)
   - Jour 2: Séance Pull (Dos, Biceps)
   - Jour 3: Séance Jambes
   - Jour 4: Séance Upper Body
   - Jour 5: Séance Full Body + Cardio

   OPTION B - CRÉATION MANUELLE
   -----------------------------
   - Clique sur "Nouveau Workout"
   - Remplis le formulaire:
     * Semaine: 1
     * Jour: 1
     * Nom: "Séance Push"
     * Description: Ce qu'on va faire
     * Durée: 60 minutes
     * Difficulté: Intermédiaire
     * Échauffement: "5-10 min cardio + étirements"
     * Retour au calme: "Étirements 10 min"
     * Notes: "Hydrate-toi bien!"
   - Clique sur "Créer le workout"


ÉTAPE 3: Vérifier que ça marche
--------------------------------
1. Va sur: https://fitgang.fr/workouts
2. Tu devrais maintenant voir tes workouts!
3. Tu peux cliquer dessus pour voir les détails


=====================================================
💡 EXEMPLE CONCRET POUR "PROGRAMME SÈCHE"
=====================================================

Pour créer un programme de sèche de 8 semaines:

1. Va sur /admin/workouts
2. Trouve "Programme sèche"
3. Utilise la création rapide:
   - Semaine 1, 5 jours → Créer
   - Semaine 2, 5 jours → Créer
   - Semaine 3, 5 jours → Créer
   - ... jusqu'à la semaine 8

En 2 minutes, tu auras 40 workouts (8 semaines × 5 jours)!

Ensuite tu peux:
- Cliquer sur "Modifier" pour personnaliser chaque workout
- Ajouter des détails spécifiques
- Changer les noms, durées, etc.


=====================================================
🎯 POUR L'EBOOK "30 JOURS POUR ÉLIMINER VOS GRAISSES"
=====================================================

Normalement un ebook N'A PAS besoin de workouts car c'est
juste un PDF à lire.

MAIS si tu veux quand même ajouter des workouts:
1. Va sur /admin/workouts
2. Trouve "30 Jours pour eliminer vos graisses"
3. Crée des workouts pour 30 jours (4 semaines)


=====================================================
✅ APRÈS LA CRÉATION
=====================================================

Teste:
1. Va sur https://fitgang.fr/workouts
2. Tu devrais voir tous tes workouts listés
3. Clique sur un workout pour voir les détails

Si ça ne marche pas:
- Vérifie que Passenger est bien redémarré (STOP puis START)
- Lance le diagnostic: python3 diagnostic_workouts.py admin@fitgang.fr
- Le nombre de workouts devrait être > 0


=====================================================
📚 STRUCTURE RECOMMANDÉE POUR UN PROGRAMME
=====================================================

Pour un programme de fitness typique:

Débutant:
- 3 jours/semaine × 4-8 semaines = 12-24 workouts

Intermédiaire:
- 4-5 jours/semaine × 8-12 semaines = 32-60 workouts

Avancé:
- 5-6 jours/semaine × 12-16 semaines = 60-96 workouts


=====================================================
🔄 MISE À JOUR / MODIFICATION
=====================================================

Pour modifier un workout existant:
1. /admin/workouts
2. Clique sur l'icône crayon (✏️) à droite
3. Modifie ce que tu veux
4. Clique sur "Mettre à jour"

Pour supprimer un workout:
1. /admin/workouts
2. Clique sur l'icône poubelle (🗑️) à droite
3. Confirme

=====================================================
🆘 PROBLÈMES COURANTS
=====================================================

Problème: "Aucun entraînement disponible" après création
Solution: Redémarre Passenger (STOP puis START, pas Restart)

Problème: Erreur 500 sur /admin/workouts
Solution: Vérifie que la table workouts existe:
  python3 create_all_tables.py

Problème: Les workouts ne sont pas dans l'ordre
Solution: Ils sont triés par semaine puis jour automatiquement

Problème: Je veux dupliquer une semaine
Solution: Pour l'instant, utilise "Création rapide" pour
  chaque semaine. La duplication arrivera bientôt!
