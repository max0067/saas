┌──────────────────────────────────────────────────────────────┐
│ MÉTHODE 1: Via cPanel phpMyAdmin (RECOMMANDÉ)               │
└──────────────────────────────────────────────────────────────┘

1. Connectez-vous à cPanel

2. Cherchez "phpMyAdmin" et cliquez dessus

3. Dans la liste à gauche, cliquez sur votre base de données FitGang
   (probablement: wrbh3411_fitgang ou similaire)

4. Cliquez sur l'onglet "SQL" en haut

5. Copiez-collez tout le contenu du fichier:
   CREATE_WEIGHT_TABLE.sql

6. Cliquez sur "Exécuter" (ou "Go")

7. Vous devriez voir: "1 requête exécutée avec succès"

8. Testez sur: https://fitgang.fr/dashboard
   Essayez d'ajouter un poids → devrait fonctionner!


┌──────────────────────────────────────────────────────────────┐
│ MÉTHODE 2: Via ligne de commande (si vous avez MySQL)       │
└──────────────────────────────────────────────────────────────┘

# Trouvez le nom de votre base de données
grep DATABASE_URL .env
# OU
grep SQLALCHEMY_DATABASE .env

# Exécutez le script SQL
mysql -u VOTRE_USER -p VOTRE_DATABASE < CREATE_WEIGHT_TABLE.sql

# OU si SQLite:
sqlite3 instance/fitgang.db < CREATE_WEIGHT_TABLE.sql


┌──────────────────────────────────────────────────────────────┐

   ❌ Si erreur: Vérifiez que la table a bien été créée
